# Documentação de API

Um arquivo por módulo (ex.: `afiliados.md`, `contratos.md`, `financeiro.md`),
criado quando os endpoints daquele módulo ficam estáveis. Ver convenção em
[`../README.md`](../README.md).

Antes de qualquer módulo ter endpoints implementados, o inventário completo
de rotas planejadas (rascunho, todos os módulos) fica em
[`mapeamento-geral.md`](./mapeamento-geral.md). Conforme cada módulo é
implementado e estabiliza, a seção correspondente deve ser promovida para o
arquivo próprio do módulo aqui e removida do rascunho geral.
